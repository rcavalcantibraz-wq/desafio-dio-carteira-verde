# Carteira Verde - Simulação de Investimentos em FIIs

Projeto desenvolvido por **Roberta Braz** durante o **Bootcamp Santander Excel com Inteligência Artificial**, em parceria com a **DIO**.

## 📋 Sobre o Projeto
O foco deste projeto é a aplicação prática de conceitos de Excel para simulação de investimentos em fundos imobiliários. 

A solução consiste em uma planilha interativa que permite ao usuário simular cenários de investimento a partir de variáveis como:
* Valor aplicado;
* Período de investimento;
* Taxa de rendimento.

## 🚀 Funcionalidades
* **Automação de cálculos:** Valor total investido e patrimônio acumulado.
* **Projeção de Dividendos:** Cálculo automático de dividendos mensais.
* **Apoio à Decisão:** Visão clara do potencial de retorno para investimentos mais informados.

## 🛠️ Tecnologias
* Microsoft Excel
* Fórmulas Avançadas / IA para análise de dados
